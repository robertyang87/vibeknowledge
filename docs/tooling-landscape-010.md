# Tooling landscape 010: emilkowalski/skills - a design engineer's animation doctrine as agent skills

Checked first-hand 2026-10-30 (repository metadata, file tree, one skill read in full).
Shared by the account owner the same day.

## Repository facts

- emilkowalski/skills - "Skills for Designers and Engineers."
- 51,478 stars, 3,012 forks, 2 open issues. Created 2026-03-16, last push 2026-10-28: active.
- MIT licence. Content is Markdown only: sixteen SKILL.md agent skills plus two
  cheatsheets (a performance cheatsheet and a UI cheatsheet). No code, no keys, no
  runtime: the entire surface is written instruction.
- The author is the design engineer behind widely used web UI components (Sonner,
  Vaul); the pack distils his animation and interface doctrine into agent-usable form.

## Contents

- Motion craft: animate, animate-expo, animation-vocabulary, animation-performance,
  find-animation-opportunities, improve-animations, review-animations (with a
  STANDARDS.md), remove-animations.
- Design judgement: emil-design-eng, apple-design, break-ui, pick-ui-library,
  prototype, mobile-native, write-swift, ask-sonner.
- Spot check: animation-vocabulary is a reverse-lookup glossary that turns a loose
  description of a motion effect into its exact term (the bouncy popover entrance is
  "pop in"; the iOS overscroll behaviour is "rubber-banding") - naming, not building.

## Assessment

- This is the craft layer, not a production engine: nothing here renders a frame.
  It competes with no lane in the index and changes none.
- The transferable part for this account is vocabulary and review discipline. Our
  films are drawn in code and judged on motion (easing, timing, holds), and the
  Treatment and self-review steps currently describe motion in ad-hoc words. A
  shared, precise motion vocabulary - and a written animation-review standard -
  would sharpen both, the same way the shotcraft cards sharpened shot language.
- The limit is domain: the doctrine is written for product UI (web and mobile
  interfaces, sub-second interaction feedback). Film timing is longer and
  narrative-driven, so the pack's terms transfer while its duration rules do not.
- The design-judgement half (apple-design, emil-design-eng, prototype) speaks to
  product-interface work outside this repository's scope; it is recorded here only
  because the pack arrives as one unit.

## Verdict

Craft reference, adopt-by-reading. Not installed as skills; if a future episode
wants the motion vocabulary, extract the relevant terms into the baseline workflow
with attribution rather than vendoring the pack. Licence (MIT) permits either.
