# Tooling landscape 015: the design-taste lane at full size - Leonxlnx/taste-skill and pbakaus/impeccable

Checked first-hand 2026-11-02 (GitHub API repository data, READMEs
and file trees read directly). Source: a screenshot card the owner
shared the same night, listing two AI skills said to raise the
design level of visual work. Both figures on the card are stale and
one name on it does not exist; the corrections are part of this
record. Filed together at the owner's direction. Nothing was
installed.

## 1. Leonxlnx/taste-skill

- 107,578 stars and 7,271 forks at this check; the card's
  "70k+ stars" understates it. Created 2026-02-19, MIT licence,
  still actively maintained (v2.1.5 on 2026-10-24, repository
  pushed 2026-10-31); the author has also shipped it as a desktop
  app, TasteCode.
- One skill (installed as design-taste-frontend) with a substantive
  SKILL.md of about 39.5 KB plus references, a library, scripts
  and evals. It runs on Node 22+ with a local Chrome, Edge or
  Chromium and needs no API keys.
- What it actually does, per its own README: it makes a coding
  agent design websites and app screens instead of assembling the
  average landing page, by giving it three things - an art
  direction, real photographs found in open archives (with a
  credits file for the pictures it uses), and a browser inspect
  loop so the agent checks its own page in screenshots.
- The card's framing, a designer reviewing arbitrary visual work,
  is a loose paraphrase: the review loop covers pages the skill
  itself generated, not film frames or other outside work.

## 2. pbakaus/impeccable - the card's "Impact-Cable"

- No repository named Impact-Cable exists on GitHub; name and
  variant searches return nothing relevant. The item is
  Impeccable, mis-transcribed by sound: Im-pecc-able splits into
  the card's two words. Two further matches confirm it: the card's
  coverage list (typography, colour, motion, detail finishing) is
  Impeccable's command set - typeset, colorize, animate, polish -
  and its command count matches an earlier version of the skill.
- 99,115 stars and 5,857 forks at this check; the card's "nearly
  50k stars" is a stale figure from earlier in the project's life.
  Created 2025-11-16, Apache-2.0, and the most active item in this
  lane: the repository was pushed the same day as this check.
- Self-description: the design vocabulary for a coding agent.
  `/impeccable init` writes a PRODUCT.md context file and
  `document` captures the existing visual system in DESIGN.md;
  every later command reads both. The current README counts 24
  commands, grouped as Steer (bolder, quieter, distill, colorize,
  typeset, layout, animate, delight, overdrive), Review (critique,
  a scored UX review; audit, a technical quality report) and
  build-and-fix verbs (shape, clarify, adapt, harden, optimize,
  polish, onboard, extract, live, doctor and others).
- The repository is sprawling by design - it ships adapter folders
  for roughly twenty-five agent tools - and its own README warns
  that its installer hooks run outside model approval in Claude
  Code. That warning is recorded here as a standing reason this
  item is read, never installed unattended.

## Assessment

- Both items serve web and app interfaces, the same lane this
  index already holds through emilkowalski/skills (landscape 010,
  51,478 stars at its filing). These two are that lane's larger
  siblings, not a new lane: neither has a timeline, subtitles,
  sound design or any fact discipline, so neither touches the
  film main line.
- What is borrowable is vocabulary and two working habits, all of
  which our baseline already practises in film terms:
  taste-skill's reference-first art direction and screenshot
  self-check map to our benchmark style extraction (baseline
  Step 3) and the two-round still-sheet gate (Step 5);
  impeccable's named steering and review verbs are a vocabulary
  source for Treatment shot language and review rubrics, the same
  adopt-by-reading slot emilkowalski/skills holds for motion
  vocabulary.
- Their real future slot is off the film line entirely: if this
  account ever builds a public web page of its own, these two are
  the first reads for its design, ahead of the smaller pack in
  landscape 010.

## Verdict

Reference shelf, adopt-by-reading, beside emilkowalski/skills:
not installed, no trial, no evaluation queue position, no change
to the main line. The card that prompted the check is recorded as
unreliable on names and figures; the figures above are the
first-hand ones.
